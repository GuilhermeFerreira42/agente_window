# 03H — Testes de Implementação: Right Sidebar

## Focados
- registrar e ativar view auxiliar;
- alternar visibilidade sem perder estado essencial;
- maximizar e restaurar quando a view permitir;
- sincronizar largura com persistência.

## E2E mínimo
1. abrir a barra auxiliar;
2. trocar entre ao menos duas views;
3. maximizar e restaurar;
4. fechar, reabrir e validar a persistência esperada.
