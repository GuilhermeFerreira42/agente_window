# Atalhos de Teclado e Comandos Globais — Fatia 10

---

## 1. Mapeamento de Atalhos (Keybindings)

| Atalho | Ação | Contexto |
|---|---|---|
| `Ctrl + N` | Cria uma nova sessão limpa | Global no Agente Window |
| `Ctrl + F` | Abre o campo de busca na lista de sessões | Na Coluna 1 |
| `Ctrl + L` / `Ctrl + Alt + I` | Foca o cursor no input do chat | Global |
| `Escape` | Cancela foco, fecha dropdowns ou cancela busca | Global |
| `Ctrl + Shift + P` | Abre o Command Palette (`>`) | Global |
| `Ctrl + W` | Fecha a sessão ativa | Na lista de sessões |

---

## 2. Comandos do Chat na Command Palette

* `Chat: New Session` — Inicia uma nova conversa com worktree limpa.
* `Chat: Clear All Sessions` — Limpa o histórico local.
* `Chat: Focus Input` — Posiciona o foco no textarea.
* `Chat: Open in VS Code` — Abre a sessão no editor principal.
